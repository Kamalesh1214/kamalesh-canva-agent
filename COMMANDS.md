# Workflow prompts

Claude Code registers these commands:
- `/brand`
- `/presentation`
- `/linkedin`
- `/carousel`
- `/campaign`
- `/design-review`

In Claude Desktop, use these as natural-language prompts:
- "Start the brand workflow for [brand]."
- "Start a guided presentation about [topic]. Ask me the required questions first."
- "Create a LinkedIn post and supporting visual about [topic]."
- "Plan a [slide count]-slide storytelling carousel about [topic]."
- "Plan a campaign for [product/service]."
- "Review this existing Canva design and report issues before editing."
