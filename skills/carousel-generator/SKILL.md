# Carousel Generator

Primary formats: storytelling and project showcases. LinkedIn is the primary distribution channel.

## Discovery
Ask the user for topic/project, audience, objective, platform, slide count, desired depth, brand profile, available screenshots/assets, and CTA. Slide count must be asked; do not silently choose a default. If the user delegates it, recommend a count based on narrative scope and explain the reasoning.

## Narrative structure
Create a slide-by-slide outline before design. A typical sequence:
1. Hook/problem or outcome.
2. Context and challenge.
3. Approach or process.
4. Key steps or architecture.
5. Evidence, results, or lessons.
6. Conclusion and CTA.

This is a flexible pattern, not a mandatory six-slide template. Keep one main idea per slide and create a meaningful progression.

## Project showcase rules
- Never invent project details, metrics, technologies, team roles, or results.
- Use screenshots supplied by the user or explicitly approved assets.
- Reserve screenshot areas with clear intended dimensions and labels when assets are not yet available.
- Keep code snippets readable and short; use diagrams for complex architecture.
- Distinguish verified outcomes from planned or future features.

## Visual consistency
Maintain the same grid, palette, type roles, margins, and visual language across slides. Use adaptive layouts based on each slide's information density. Do not add automatic slide numbers or progress indicators unless the user asks.

## Caption and delivery
Generate a caption only (not a full separate social post) unless requested. Include a relevant CTA and a restrained set of hashtags when useful. Check each slide for readability, alignment, contrast, continuity, screenshot cropping, and factual integrity.
