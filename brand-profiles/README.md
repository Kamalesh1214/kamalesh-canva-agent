# Brand profiles

Store each brand in its own directory. Do not mix profiles.

Recommended structure:

```text
brand-profiles/
  kamalesh/
    current.json
    CHANGELOG.md
    v1.0.0/
      brand-profile.json
  client-example/
    current.json
    CHANGELOG.md
    v1.0.0/
      brand-profile.json
```

`current.json` should identify the approved current version. Preserve older version snapshots. The included `kamalesh` profile is an initial draft based on the user's stated direction and must be reviewed before treating logo concepts or exact serif font selection as final.
